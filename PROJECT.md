# Floyd Equipment Rental Website

## Mission

Build the most professional equipment rental website in Southwest Virginia. Every page should make it easier for customers to choose, reserve, and confidently use professional equipment.

The website should feel premium, trustworthy, modern, and easy to use.

Think Apple meets Kubota.

---

## Customers

- Homeowners
- Farmers
- Landowners
- Hunters
- People maintaining trails and fields
- Residents of Floyd County, Virginia

## Business Philosophy

We don't just rent equipment.

We teach people how to use it safely.

Our goal is to become the trusted equipment experts in Floyd County.

---

## Development Rules

Never rebuild pages from scratch.

Always improve the existing files.

Never remove working sections without approval.

Keep HTML semantic.

Keep CSS organized.

Prefer reusable components.

Every release should improve the previous release.
