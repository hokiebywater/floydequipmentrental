# Floyd Equipment Rental Design System

## Purpose

This document defines the visual language for the Floyd Equipment Rental website.

Every page should feel like it belongs to the same professional brand.

When making design changes, follow this document before introducing new layouts, colors, spacing, or components.

---

# Brand Personality

Professional

Dependable

Modern

Helpful

Local

Premium

Simple

Never flashy.

Never cluttered.

Never gimmicky.

---

# Overall Inspiration

Think:

• Apple
• Kubota
• Caterpillar (clean product pages)
• John Deere commercial products

Avoid:

• Generic construction templates
• Rustic country themes
• Busy layouts
• Flashy animations

---

# Design Goals

The website should immediately communicate:

1. Professional equipment
2. Local service
3. Trust
4. Ease of renting

---

# Colors

Use the existing CSS variables.

Primary:

- Deep Green

Accent:

- Hunter Orange

Background:

- Warm Cream

Text:

- Dark Charcoal

Use orange only for calls-to-action and important highlights.

Do not introduce additional accent colors.

---

# Typography

Headings

Montserrat

Bold

Large

High contrast

Body

Inter

Comfortable reading size

Generous line spacing

Avoid decorative fonts.

---

# Layout

Use generous whitespace.

Content should never feel cramped.

Prefer wider margins over squeezing more content onto the page.

Maximum content width:
1200px

Sections should breathe.

---

# Buttons

Buttons should look substantial and clickable.

Primary buttons:

- Orange
- Rounded corners
- Subtle shadow
- Gentle hover lift

Secondary buttons:

- Outline or white
- Never compete with the primary CTA

---

# Cards

Cards should have:

- Rounded corners
- Soft shadows
- Plenty of padding

Never use heavy borders.

---

# Photography

Photography is one of the highest priorities.

Preferred images:

Real equipment

Real Floyd County

Real customers

Real projects

Avoid:

Stock construction workers

Generic excavators

Artificial-looking AI imagery

Product photography should be:

Large

Sharp

Well lit

High resolution

---

# Equipment Pages

Every equipment page should contain:

Hero photo

Specifications

Benefits

Ideal projects

Rental requirements

Frequently asked questions

Reserve button

Related equipment

---

# Homepage

The homepage is NOT a catalog.

Its purpose is to convince visitors to rent equipment.

It should:

Build trust

Highlight featured equipment

Explain why Floyd Equipment Rental is different

Lead visitors toward a reservation

---

# Animations

Animations should be subtle.

Examples:

Fade in

Small lift on hover

Gentle transitions

Avoid:

Bounce

Spinning

Flashing

Large movements

---

# Icons

Use clean SVG icons.

Keep icon style consistent throughout the site.

Avoid emoji.

---

# Mobile

Design mobile first.

Buttons should be easy to tap.

Navigation should remain simple.

Cards should stack naturally.

---

# Accessibility

Maintain sufficient color contrast.

Use semantic HTML.

Every image requires descriptive alt text.

Keyboard navigation should work.

---

# Coding Standards

Do not redesign sections unless requested.

Modify existing components whenever possible.

Keep CSS organized by section.

Avoid duplicate rules.

Use existing color variables.

Preserve responsive behavior.

---

# Development Philosophy

Every release should make the website feel slightly more polished.

Small improvements over large redesigns.

Consistency is more important than novelty.

When in doubt:

Choose the cleaner,

simpler,

more professional solution.
