Only work on one release at a time.

Complete, test, and commit each release before moving to the next.

# Long-Term Vision

The Floyd Equipment Rental website should become the most professional equipment rental website in Southwest Virginia.

Every page should help customers:

- Find the right equipment
- Understand what it does
- Feel confident renting it
- Reserve it quickly

The website should always reflect the company's values:

- Professional
- Dependable
- Local
- Helpful
- Modern

Every release should improve the existing website.

Never redesign the site without a specific objective.

Favor small, polished improvements over major redesigns.
